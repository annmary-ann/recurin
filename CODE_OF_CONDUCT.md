# Code of Conduct

recurin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good intent, and keep discussion about the work.

## Scope

This applies in all project spaces: issues, pull requests, discussions and any official channel. It also applies when someone is representing the project elsewhere.

## Reporting

To report unacceptable behaviour, use GitHub's **Report content** option on the comment, issue or pull request. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits, code and issues that break this code, and may temporarily or permanently ban contributors whose behaviour is harmful. Enforcement follows the guidelines in the Contributor Covenant.
